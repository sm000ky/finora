## 🌟 Apa itu Finora?

**Finora** adalah studio pembukuan dan akuntansi web terpadu yang dirancang untuk UMKM, mahasiswa akuntansi, dan praktisi keuangan di Indonesia. Menggabungkan kemudahan UI modern bernuansa pastel elegan dengan ketepatan standar akuntansi resmi (SAK EMKM) dan regulasi perpajakan terbaru.

## ✨ Modul & Kapabilitas Utama

### 1. 📖 Journal Studio (Jurnal Umum SAK EMKM)
- Input transaksi debit & kredit otomatis tervalidasi balance.
- Preset template bisnis siap pakai: Kafe/F&B, Retail Online Shop, dan Jasa Konsultan.
- Auto-generate Neraca Saldo dan Laporan Posisi Keuangan secara *real-time*.

### 2. 🧾 AI Transaction Parser & Struk-to-Jurnal
- Ekstrak teks mutasi rekening atau struk belanja mentah menjadi baris jurnal berpasangan yang seimbang.
- Deteksi otomatis akun beban, kas, dan utang usaha.

### 3. 💼 Payroll & PPh 21 TER Engine (PP 58/2023)
- Perhitungan akurat skema TER Kategori A/B/C terbaru.
- Rincian potongan BPJS Ketenagakerjaan & Kesehatan.
- Cetak langsung format slip gaji karyawan siap unduh.

### 4. 📈 Arus Kas & PPh Final UMKM 0,5%
- Klasifikasi arus kas operasional, investasi, dan pendanaan.
- Kalkulasi PPh Final UMKM (PP 55/2022) dengan fasilitas omzet tidak kena pajak sampai Rp 500 Juta.

### 5. 📗 4-Sheet Excel Generator Engine (ExcelJS)
- Export seluruh siklus akuntansi menjadi 1 file `.xlsx` profesional:
  1. Sheet 1: Profil Bisnis & Ringkasan Eksekutif
  2. Sheet 2: Jurnal Umum Berpasangan
  3. Sheet 3: Neraca Saldo
  4. Sheet 4: Laporan Laba Rugi Sederhana

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite
- **Styling:** Tailwind CSS (Mode Terang & Gelap)
- **Spreadsheet Engine:** ExcelJS (Client-side native .xlsx builder)
- **Audio & Visual FX:** Web Audio API Sound FX + Confetti Celebration

## 🏁 Cara Menjalankan

```bash
# Clone repository
git clone https://github.com/sm000ky/finora.git

# Masuk ke direktori
cd finora

# Install dependensi
npm install

# Jalankan lokal server
npm run dev
```

Buka `http://localhost:5173` di browser kamu.
